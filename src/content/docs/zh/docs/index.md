## miao

在终端里运行的开源 AI 编程代理：模型由你选，长任务可中途调整，花费看得见。

- [使用指南](/zh/docs/miao/guide/) —— 安装、连接供应商、配置权限、MCP 与 LSP，以及排障
- [版本管理与发布](/zh/docs/miao/release/) —— 版本如何编号、构建和发布
- [miao 与 opencode 的对比](/zh/docs/miao/miao-vs-opencode/) —— 这个分支的工作落在哪里，附实测数据与可用性

## mtty

用 Rust 编写的快速、可嵌入、跨平台的终端模拟器与引擎。应用以 `mtty` 的名字发布。

- [概览](/zh/docs/mtty/) —— 当前状态、下载、从源码构建，以及其余文档在哪里
