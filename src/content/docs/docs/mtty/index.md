mtty is a terminal emulator and engine written in Rust, built as one engine library plus a full application on top of it.

It has not had a stable release. The current version is 0.0.4 and the API is still moving, so build it from source and expect rough edges.

The documentation is being migrated to this site. Until that is done, the repository carries the build instructions and the architecture notes:

- [oxdingzg/miao-term](https://github.com/oxdingzg/miao-term) — source, build instructions, and the architecture decision records
